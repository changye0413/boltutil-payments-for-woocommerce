# Release copy — plugin v0.6.1

## Repository description

WooCommerce USDT/USDC payments on six networks, including Base. Hosted checkout with wallet confirmation or manual transfer, signed Webhooks, and 12 UI languages. Plugin v0.6.1.

Repository demo website: https://shop-test.boltutil.com/

## English announcement

Accept USDT and USDC in WooCommerce with BoltUtil. Customers choose a stablecoin and one of the available networks, then continue to Hosted Checkout. On supported devices, connect a wallet to fill in the address and exact amount, review and confirm; manual transfer is also available. Confirmed payments are checked before the plugin updates the order.

Plugin v0.6.1 supports six networks and eleven token/network combinations, including native USDC and Bridged USDT on Base. It includes twelve interface languages and replaces fixed daily quota wording with the current daily allowance and subscription terms on the BoltUtil website.

Try the public demo: https://shop-test.boltutil.com/ . Browsing is free; small digital purchases use real funds. Download: https://github.com/changye0413/boltutil-payments-for-woocommerce/releases/tag/v0.6.1 . This is an early release; real payment/callback acceptance and WordPress.org approval remain pending.

## Publishing rules

- Plugin v0.6.1 and BoltUtil Hosted Checkout/service v2.1 are different version lines.
- Quick-payment options depend on network, token, device and wallet support. Do not promise every wallet on every chain.
- Use the exact Hosted Checkout amount; fees are separate. No fixed Base confirmation time is promised.
- Product screenshots show real interface states, not proof that a blockchain payment completed.
- Source docs are available in eleven translated introductions linked from README. Runtime translations follow WordPress locales; merchant-written labels do not translate automatically.
- Do not claim WordPress.org listing, automatic refunds, guaranteed search ranking, universal free payments or unlimited order benefits outside the published subscription terms.
